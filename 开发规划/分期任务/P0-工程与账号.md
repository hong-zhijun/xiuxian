# P0：工程与账号

目标：提供能持续开发和测试的真实基座；本期不实现经营玩法。

Cloudflare修订：本地Wrangler+模拟D1，无Docker。前端部署为 Cloudflare Pages 项目，后端部署为 Cloudflare Workers 项目，通过同域 Route 连接。远程资源创建和部署须授权，本期本地开发不自动连接生产。

顺序：P0-01 → P0-02 → P0-03 → P0-04 → P0-05 → P0-06 → P0-07。

## P0-01 工程初始化与版本锁定

- 前置：确认技术基线，阅读 02；检查目录现状，不覆盖原始需求/规划。
- 范围：package.json/workspaces、apps/web、apps/server、packages三目录、tsconfig/lint、wrangler.jsonc、.gitignore、docs/setup.md。
- 实现：核对本地Node/Vite/Wrangler/Hono/Zod兼容版本；创建Vue项目（apps/web）与Worker项目（apps/server）各自的 wrangler 配置；Vite dev server 代理 `/api/*` 到 Wrangler 本地 Worker；Worker fetch/health 端点；Vite build.target=['chrome109','firefox115']；生成绑定类型；lockfile 和 .dev.vars.example。授权后才初始化Git，不自动提交。
- 验收：无Docker可安装/typecheck/build；Vite+Wrangler并行开发模式正常；Web经proxy获取serverTime；Worker独立启动可响应API；未知API返回JSON404不是HTML；PowerShell命令可用。
- 测试：包导入、Worker health、静态资源/API路由；记录工具版本与compatibility_date。
- 禁做：业务页面、登录伪实现、单体大文件 App、未验证最新依赖混装。

## P0-02 数据库与迁移基座

- 前置：P0-01。
- 范围：DB binding、migrations/*.sql、infra/db参数化仓储、本地D1测试状态、seed。
- 实现：Wrangler本地D1；User/Session/GameServer/ConfigVersion；INTEGER时间与安全整数；外键/CHECK/唯一约束；ready检查DB；幂等seed不清存档；开发与测试状态目录隔离。
- 验收：空本地D1迁移成功；seed重跑不重复；生产/未知远程绑定执行测试立即失败；模拟D1异常时ready失败、live仍能响应。
- 测试：在workerd/D1中验证迁移、唯一约束、错误映射、seed重跑；记录状态目录与环境。
- 禁做：Docker/PostgreSQL安装要求、ORM自动清库、用普通SQLite驱动冒充D1、默认连远程生产。

## P0-03 契约、配置和统一错误

- 前置：P0-02。
- 范围：contracts、game-config、game-core/config、Hono错误中间件与Workers结构化日志。
- 实现：04 的响应包、错误码、严格输入 schema；UTC 时间与资源字符串类型；configVersion 加哈希校验；配置引用/重复 ID/负成本检查；requestId；日志脱敏。

## P0-04 真实账号、Session 和 CSRF

- 前置：P0-03。
- 范围：modules/auth、session/csrf/rate-limit 插件、受控账号脚本。
- 实现：注册开关/邀请、登录/me/退出；核验Workers兼容的成熟密码哈希实现与参数，见02，不使用Node原生二进制依赖；Cookie/Session摘要和期限；Origin/CSRF；跨实例限频；受控创建账号/撤销session。
- 验收：注册关闭不可绕过；错密码不泄露账号存在性；登录无需预先持有session token；退出/过期失效；跨源或已登录无CSRF不能写；日志无密码/token。
- 测试：A01/A02/A05，Cookie、重复账号、撤销session、跨Worker实例限频；密码哈希的workerd兼容性/耗时与云端预算验证，未验证不开放注册。
- 禁做：明文密码、JWT 放 localStorage、万能管理密码、未鉴权调试接口。

## P0-05 事务、幂等、时钟和随机源

- 前置：P0-04。
- 范围：CommandReceipt/MutationGuard迁移、infra/command-plan/batch、game-core/time/random。
- 实现：02的读取一致快照→纯计算→单batch断言版本与条件→业务写入+回执；scope/key/hash唯一；CHECK(valid=1)Guard；有限冲突重试、结果重放；Clock/RNG注入；生产禁固定测试源。
- 验收：同key并发只提交一次；改body409；Guard失败、后续SQL失败、唯一键冲突均整体回滚；UPDATE零行不能继续发奖；提交后响应丢失可重放；无BEGIN/FOR UPDATE/交互式tx。
- 测试：A03/A04/S09；本地D1并发/失败注入；通过测试仓储的版本计数验证，不依赖尚未创建的Sect；P1再接真实资产，远程staging在授权后复测。
- 禁做：内存锁/Map当一致性保证；分多次batch扣款发货；ON CONFLICT DO NOTHING吞业务冲突；提交后才检查0行再补偿。
