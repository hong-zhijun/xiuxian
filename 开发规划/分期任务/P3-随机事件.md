# P3：随机事件系统

3~5 人自用娱乐游戏。已有基座：完整挂机循环（资源产出、弟子招募/分配/突破、建筑升级），每次 sync 会先结算离线收益。

本任务在结算时随机触发事件，让挂机不那么无聊。

**核心原则：简单直接。事件就是一个随机判定+效果执行，没有持续事件、没有选择分支、没有事件链。**

## 二、事件定义 (apps/server/src/modules/game/events.ts)

新建文件。定义事件池，每个事件：

```typescript
interface EventDef {
  id: string;
  name: string;
  description: string; // 会显示给玩家的文案
  weight: number;      // 权重，越大越容易触发
  effects: EventEffect[];
}

interface EventEffect {
  type: 'resource';      // 目前只做资源增减
  resourceId: string;    // 对应 game-config 里的资源 id
  amount: string;        // 最小单位，正数=获得，负数=扣除（扣到 0 为止不会负）
}
```

## 三、结算时触发 (修改 apps/server/src/modules/game/settle.ts)

在现有的 `settle` 函数**末尾**加事件判定逻辑（不改动已有的资源/修为结算）：

1. **触发概率**：每次结算，按经过的时间计算触发次数。每小时有 30% 概率触发一个事件。
   - `expectedEvents = elapsedHours * 0.3`
   - `eventCount = Math.floor(expectedEvents) + (Math.random() < (expectedEvents % 1) ? 1 : 0)`
   - 单次结算最多触发 3 个事件（离线 12 小时最多 3 个，不要刷屏）
2. **选事件**：按权重随机（`Math.random()` 加权选择）
3. **执行效果**：直接修改结算结果里的资源余额（加/减），资源不低于 0、不超过容量
4. 在 `SettleResult` 里加一个 `events: TriggeredEvent[]` 字段，包含触发的事件 id、name、description、effects

## 六、前端

**重要：前端已经被完全重构过，样式和组件结构与任务卡原始版本不同。你必须先读以下文件了解当前代码结构：**

- `apps/web/src/styles/base.css` — 完整样式系统（翡翠绿+暗金配色，CSS 变量如 `--jade`、`--gold`、`--red` 等）

- `apps/web/src/components/ToastStack.vue` — Toast 通知组件
- `apps/web/src/components/AssignmentSelect.vue` — 自定义下拉选择组件

### 6.1 事件通知（用已有的 Toast 系统）

sync 返回数据后，如果 `recentEvents` 里有最近 5 分钟内的新事件（对比上一次 sync 的事件列表），用已有的 `emit('notify', tone, title, message)` 发 toast：
- 好事件（资源增加）：tone = `'success'`
- 坏事件（资源减少）：tone = `'warning'`
- 混合事件：tone = `'info'`

### 6.2 事件日志面板

在 `management-rail`（右栏，建筑面板下方）加一个事件日志面板。沿用现有的样式模式：

```html
<section class="game-panel event-panel">
  <header class="section-heading panel-heading compact-heading">
    <div>
      <p class="eyebrow">天机录</p>
      <h2>近期异象</h2>
    </div>
  </header>
  <ul class="event-list">
    <li class="event-card">...</li>
  </ul>
</section>
```

每条事件显示：时间 + 事件名 + 资源变化（正数用 `--jade` 色，负数用 `--red` 色）。在 `base.css` 里加对应的 `.event-panel`、`.event-list`、`.event-card` 样式，风格与现有的 `.building-card` 保持一致（圆形图标 + 文字 + 紧凑布局）。

### 6.3 API 类型

在 `apps/web/src/api/game.ts` 里：
- `SectStateView` 加上 `recentEvents: EventLogView[]`
- 加 `EventLogView` 类型定义
