# P1：核心挂机闭环

目标：注册 → 建宗门 → 派弟子 → 离线收益 → 建筑/灵脉/宗门升级 → 突破。单服服务端存档，仅内部试玩。

顺序：01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09。

## P1-01 宗门初始化和基础存档

- 前置：P0 完成。
- 范围：P1 实体 migration、配置、modules/sect、创建接口、contracts。
- 实现：03 定义的 Sect/ResourceBalance/Building/Disciple/Ledger/Chronicle/DailyCounter；四资源、三建筑、两境界；建宗门事务一次创建完整初始状态；配置宗门等级、灵脉、容量与建筑解锁。
- 验收：同账号同服并发创建仅一宗门；起始资源/岗位/人数正确；失败不留半宗门；名字非法拒绝；其他用户不可读。
- 测试：创建/重复/回滚/外键/唯一约束；seed 重跑不重置资产。
- 禁做：一次生成后续所有系统表、前端创建默认余额、账户资金与灵石重复建账。

## P1-02 离线结算纯函数

- 前置：P1-01。
- 范围：game-core/settlement、单位转换、相关测试。
- 实现：输入旧快照/L/N/配置，输出资源和修为差量、余量、溢出、lastSettledAt；12h 上限；负时间；仓满；修为门槛停止；不做 IO。
- 验收：03示例一致；未触顶碎片结算等价；纯计算BigInt无浮点误差，落D1前安全范围检查；上限外不顺延；不自动突破。
- 测试：S01/S02/S04/S05、随机分段性质测试、极大值边界。
- 禁做：真实 Date.now、数据库读写、前端依赖、按秒逐 tick 模拟。

## P1-03 结算服务、同步和资产流水

- 前置：P1-02/P0-05。
- 范围：modules/settlement、asset 服务、sect/sync、SectSnapshot、流水查询测试工具。
- 实现：读取Sect一致快照，固定serverNow；纯计算旧状态收益及命令；单D1 batch断言预期stateVersion、原子落余额/版本/流水/回执；冲突有限重试；公共“先结算再命令”入口；GET只读。
- 验收：10 个并发 sync 只按真实经过时间增加资产；结算半途异常回滚；响应乱序不改最新状态；同 key 重试不重算收益。
- 测试：S03/S07/S08/S09；本地D1；GET无写；断言冲突回滚；流水接受量与余额对齐。
- 禁做：多个服务各实现一套结算、把 GET 变成隐藏领奖接口。

## P1-04 弟子列表、详情与招募

- 前置：P1-03。
- 范围：modules/disciple、招募配置、姓名/资质生成器、列表详情 DTO。
- 实现：安全姓名、灵根/资质/天赋/性格、年龄寿元展示；3 名初始弟子；每日 3 次招募、50 灵石；人数上限；招募结果幂等；入宗史册。
- 验收：满员/不足不扣费不耗次数；伪造属性拒绝；同 key 返回同一人；其他宗门弟子详情不可见。
- 测试：D01/D02、UTC+8 跨日次数、固定 RNG 生成、非法姓名。
- 禁做：付费刷新池、无限免费重抽、随机结果仅存浏览器。

## P1-05 岗位分配和产量来源

- 前置：P1-04。
- 范围：assignment 服务、rate calculator、公共 DTO。
- 实现：idle/cultivating/herbGathering/oreGathering；岗位容量来自建筑配置；互斥校验；变更前按旧状态结算；显示最终速率和加成来源。
- 验收：同人不能同时采矿修炼；岗位满/受伤不可派；换岗前后产量分别正确；弟子未安排时不偷算收益。
- 测试：S06、并发派到最后一个岗位、资质/天赋上限、零产量。
- 禁做：给每个岗位建独立计时器、只由前端决定占用。

## P1-06 建筑、宗门和灵脉升级

- 前置：P1-05。
- 范围：modules/building、sect upgrades、配置、成本预览。
- 实现：三类升级入口；服务器成本；expectedLevel；先结算旧等级；容量/弟子/建筑上限随配置变化；P1 建筑即时升级。
- 验收：同等级连点不多升；不足不变更；满级拒绝；先结算再增加仓容，不能用新仓补已丢的溢出；宗门 Lv1→2 无声望死锁。
- 测试：成本边界、S06、并发升级、类型/等级越界、容量变更。
- 禁做：尚未规划的建筑工人和排队系统、客户端上报升级价格。

## P1-07 修炼与境界突破

- 前置：P1-06。
- 范围：game-core/cultivation、breakthrough 服务、冷却和史册。
- 实现：炼气/筑基各阶段；门槛、速率、成本、概率；成功清修为，失败保留90%与5分钟冷却；仅允许已实现加成；结果一次落库。
- 验收：未满修为/冷却/伤势/最高已开放阶段均不可非法突破；失败不死亡；同 key 不重掷；显示概率等于服务端实际概率。
- 测试：D04、0/10000 边界模拟、最低最高概率 clamp、修为满后停止、突破回滚。
- 禁做：自动突破、暗中改概率、偷用 P2 尚未实现丹药。

## P1-08 接通核心游戏页面

- 前置：P1-01～07。
- 范围：创建宗门、总览、弟子、建筑、史册；路由与快照 store。
- 实现：进入先 sync；资源条与容量；离线已到账摘要；派工、招募、升级、突破确认与结果；实时倒计时只作显示；60秒轮询和隐藏暂停。
- 验收：全链路真实数据；刷新后状态保留；重复点击只发一个意图；断网结果不明可用原 key 确认；大数字、满仓、空列表不溢出。
- 测试：核心 E2E、手机/桌面截图、过时响应 stateVersion 测试、多标签页。
- 禁做：假资源、空功能导航、弹出收益框后再次领取同笔收入。

## P1-09 并发回归、节奏模拟与内测交付

- 前置：P1-08。
- 范围：tests、模拟脚本、docs/verification/P1、调参记录。
- 实现：用测试时钟模拟5分钟/1天/3天；检查所有资源来源消耗、无玩法卡死；跑 A/S/D 已涉及用例；邀请账号内测说明。
- 验收：至少2账号独立全流程；离线30h只给12h；篡改客户端/多标签/异常回滚不能多领；首次核心循环符合01节奏目标或记录并修正配置。
- 交付：可运行 P1、测试/截图、问题清单、完整存档示例、P2准入评审。
- 禁做：为赶进度加商城卖资源、跳过结算一致性直接开发多人。
