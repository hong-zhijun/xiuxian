# 产品范围与分期决策

## 1. 定位

玩家是掌门，核心体验是“安排弟子 → 离线成长 → 回来处理变化 → 提升宗门”。

强约束：网页可玩；Chrome 109 / Firefox 115 ESR；一次上线 3～10 分钟；服务端权威；异步多人；竞争失败不掠夺资产；公开信息不泄露私有库存和秘密功法。

单人经营不是本地存档，P1 起即使用服务端账号与数据库。

## 2. 范围追踪

| 原始需求 | 交付 | 边界 |
| --- | --- | --- |
| 宗门名称/等级/声望/资金/灵脉/容量/州服 | P1 | 单服，字段预留，不跨服 |

| 藏经阁、炼丹房、炼器阁 | P2 | 研究、传承、炼制完整小闭环 |
| 护山大阵、灵兽园 | P6 | 灵兽养成与材料产出，无战斗技能树 |

| 弟子基础属性/灵根/资质/天赋/状态 | P1 | 年龄寿元先存储展示，P3 推进 |

| 宗门公开档案 | P4 | 白名单 DTO |

对外说首版时，必须注明 P1 试玩、P3 内容测试或 P6 完整 V1.0；延期项不能标成已完成。

## 3. 最小内容量

| 阶段 | 最低交付内容 |
| --- | --- |
| P1 | 4 种资源、3 座建筑、3 名初始弟子、2 境界、10 条安全姓名片段 |
| P2 | 6 座建筑、3 境界、6 本功法、4 丹方、3 法器配方、3 地区各 3 历练、3 策略 |
| P3 | 5 境界、6 关系类型、18 个事件、3 条两步以上事件链、2 种隐退传承 |
| P4 | 4 榜、20 个开发用演示宗门、礼物/论道/参悟各 1 套规则 |
| P5 | 丹药/药材/矿石/法器/功法残页各至少 1 条真实产销路径 |
| P6 | 灵兽材料产销、2 种妖兽模板、2 类灵兽、8 类建筑 |

以上只是数据驱动验收门槛。生产不能把演示宗门伪装成真实玩家。

## 4. 节奏目标

- 首次 5 分钟：建宗门、看弟子、派工、升级建筑。
- 累计 20～30 分钟：首个突破或历练结果。
- 第一天：提升产能与培养核心弟子存在实际资源取舍。
- 前三天：资源持续消耗、岗位有选择，不被一套阵容垄断。
- 不做强制签到链、错过永久损失和排行榜核心资源滚雪球。
- 这些须通过模拟与真人试玩验证，生产没有时间加速入口。

## 5. V1.0 不做

实时聊天/战斗、跨服、联盟战争、捏脸、移动地图、支付、竞价、部分成交、任意转账、抄家、弟子自动永久死亡、AI 动态剧情、微服务。

灵根先做成长修正；法器为固定模板和少量词条；功法为固定等级，不展开复杂相克、洗练或程序生成。

## 6. 阶段退出条件

- P0：可复现启动；登录真实；测试隔离；鉴权/事务/幂等可测试。
- P1：招募、派工、离线、升级、突破闭环；重试/多标签页/改客户端时钟不多领。
- P2：采集、炼制、装备、战斗、历练闭环；边界与战报可复现。
- P3：人物事件关系影响成长；五境界可用；风险人生功能可关闭。
- P4：两真实账号可互动，不能查看对方私有数据。
- P5：订单资产守恒；双买、重试、过期竞态在本地D1和staging远程D1验证通过。
- P6：妖兽并发/发奖、目标浏览器、备份恢复、需求核对全通过。
