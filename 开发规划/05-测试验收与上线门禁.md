# 测试验收与上线门禁

## 1. 单任务完成定义

必须同时具备：真实实现、输入校验、权限校验、错误状态、对应测试、可重复执行命令、修改文件列表和证据记录。有新数据结构则还需迁移与旧数据验证。

“代码看起来没问题”“页面能打开”“mock 接口成功”不能替代数据库与业务验收。未执行测试明确标为未执行，任务进入待验收，不写完成。

测试使用隔离的本地D1状态目录/测试存储；云端只用独立staging D1，执行前核对环境、database_id和Worker binding。测试不能使用生产绑定，清理本地状态前验证绝对路径。

## 3. 资产与时间不变量

- 任何提交后资源非负、不超过指定储存上限；托管、邮件另有明确存储位置。
- 不可消费的资产位置不能再作为可用余额返回。
- sum(买方扣款) = sum(卖方增加或应收邮件) + sum(税)。
- 同来源奖励领取最多一次，邮件存在本身不等于已到账。
- lastSettledAt 不倒退；同一时间段不重复生产；有限任务不会因为 worker 重启重开。
- 每名弟子最多一个岗位；同时远征不能参与另一需占用任务。
- 同幂等键随机结果一致；重新播放战报无业务写入。

为这些不变量做随机序列/性质测试：固定种子组合 sync、升级、派工、重试、满仓、失败回滚，发现失败打印可复现实例。

## 4. 浏览器与界面验收

| 环境 | 必测 |
| --- | --- |
| Chrome 109 / Windows 7 | 生产包登录、总览、派工、突破、列表、购买流程 |
| Firefox 115 ESR / Windows 7 | 同上；Cookie、日期、滚动、字体与 CSS |
| 现代 Chromium/Firefox/WebKit | Playwright 主流程回归 |
| 桌面 1366×768、1920×1080 | 不遮挡、主要操作可见、表格可扫描 |
| 手机 390×844、360×800 | 无整页横滚、按钮不重叠、弹窗可关闭 |

旧浏览器安装包/虚拟机只能来自可信来源，不关闭 TLS 安全验证绕兼容问题。暂时无目标环境时标“未验证，禁止宣称兼容达标”，不影响单元测试继续推进。

每个页面测试 loading/empty/error/success、session 过期、多标签页、连点、断网、恢复；用截图检查文本溢出。概率和交易确认不可只用颜色区分。

## 5. 吞吐量与上线基线

暂按单服1000注册、100活跃会话、峰值20请求/秒设计，待P6确认。这是待验证目标，不是免费套餐承诺。前端由 Pages 项目托管，后端由 Workers 项目承载 API/scheduled，共用一个 D1 数据库；Cloudflare按平台方式执行，不设常驻API进程。

使用授权staging Worker/D1压测，记录套餐、compatibility_date、部署版本、请求地区、数据量、并发、请求比例、每请求SQL数量及读写行数。目标不是保证值：普通读p95<300ms、sync p95<800ms、有限战斗<2s、非预期错误<1%；以真实用户地区测量后调整，不套用VPS核数配置。

P5/P6单独做同订单/同Boss热点压测；记录版本冲突率、重试次数、D1批次延迟/错误、读写行数、Worker CPU/内存限制与配额。达到响应时间但资产不正确仍失败；单库吞吐不足时先减少轮询和冗余查询，不盲目按玩家分库破坏交易原子性。

## 6. 部署、备份与可恢复性

- 生产关闭测试接口；检查 Pages SPA 回退、Workers Route `/api/*` 优先级、HTTPS、同域 Cookie Secure、CSRF、注册开关、D1 binding 与 Secrets。
- 建立API健康检查、scheduled执行记录、失败任务列表、Workers日志与D1配额告警；不是VPS磁盘/进程监控。
- 指标：sync时长、D1批次延迟、版本冲突/重试、幂等重放、任务积压、未发奖励、CPU预算、5xx与成本。
- 使用D1 Time Travel，并核对所选套餐恢复窗口；关键迁移前记录bookmark；定期导出到受控独立存储，保留周期按运营需求确认，不假设所有套餐保留期一样。
- RPO/RTO上线前依据D1恢复能力与实测确定；交易灰度前验证恢复到目标bookmark及恢复耗时，不按自建库方式管理WAL。
- 上线前在独立staging环境演练恢复；恢复前禁止相关写入/调度，恢复后核对订单/任务/邮件、幂等记录和迁移版本，再恢复服务。不得未经授权回档生产。
- 数据迁移采用先扩展再收缩，应用回滚兼容旧字段；不可逆迁移不假装支持一键回滚。
- 资产事故：关闭对应功能开关，保留流水，查来源，再用带审计和幂等的原子批次补偿；不直接手改余额掩盖问题。回档会影响之后全部合法交易，不能当作单笔补偿手段。

## 7. 门禁顺序

每任务：相关单测/集成测试 + typecheck/lint。

每期：全套已有测试 + build + 该期端到端 + 迁移 + 任务证据评审。

公开上线：全部非延期需求 + 真旧浏览器 + 并发守恒 + 无越权 + 备份还原 + 配置发布 + 故障演练。任一资产/权限致命缺陷存在即 No-Go。
