# 灵兽竞逐（赌坊第三玩法 · 替换即时赛马）

> 10 分钟一轮、全服公共投注池、互赌倍率实时变动的灵兽竞速。

## 1. 核心规则

| 项目 | 说明 |
|------|------|
| 轮次周期 | 10 分钟（对齐整 10 分钟：:00 / :10 / :20 / :30 / :40 / :50） |
| 投注阶段 | 前 8 分钟（接受下注） |
| 封盘阶段 | 后 2 分钟（不再接受下注，展示赛跑动画） |
| 结算触发 | Cron Trigger `*/10 * * * *`（每 10 分钟的 :00 秒执行 `scheduled()`） |
| 运营时段 | UTC+8 08:00–23:00（末轮 22:50 开始，23:00 结算；23:00–08:00 休赛） |
| 灵兽数量 | 5 只：麒麟、玄龟、朱雀、白虎、青龙 |
| 投注类型 | 仅冠军（v1） |
| 每注范围 | 10–500 灵石（展示单位，= 10000–500000 最小单位） |
| 每轮多注 | 同一玩家可对同一灵兽或不同灵兽下多注（累加入池） |
| 每日额度 | 共享 50 次/天（与论道、天机轮相同）；同一轮只扣 1 次（首注扣） |

## 2. 倍率计算（互赌/Parimutuel）

```
净池 = 总投注额 × (1 − 抽水率)          // 抽水率 10%
冠军池 = 该灵兽上的总投注额
倍率 = 净池 / 冠军池                    // 动态，随投注变化
玩家奖金 = 玩家在冠军灵兽上的投注 × 倍率  // floor 到最小单位整数
```

- 无人投注的灵兽：倍率显示为 "—"
- 只有一只灵兽有投注：倍率 = 0.9（保底，因为自己赌自己 × 0.9）
- 冠军灵兽无人投注：所有投注归庄（全输）

## 3. 冠军决定

每只灵兽在轮次创建时生成 1–5 的整数权重（从 round_key 确定性派生），权重之和决定胜率。  
结算时用 `Math.random()` 加权随机选冠军（与旧赛马同逻辑）。

## 4. 数据库（migration 0024）

### race_rounds

| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | UUID |
| round_key | TEXT UNIQUE | UTC+8 对齐的轮次标识，如 `"2026-09-23T08:00"` |
| beast_weights | TEXT | JSON `[3,2,5,1,4]` |
| status | TEXT | `'betting'` / `'settled'` |
| winner_index | INTEGER | 结算后填入（0–4）|
| total_pool | INTEGER | 所有注的总和（最小单位） |
| settled_at | INTEGER | 结算时间戳 |
| created_at | INTEGER | 创建时间戳 |

### race_bets

| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | UUID |
| round_id | TEXT FK | → race_rounds.id |
| sect_id | TEXT FK | → sects.id |
| beast_index | INTEGER | 0–4，CHECK |
| amount | INTEGER | 最小单位，CHECK > 0 |
| created_at | INTEGER | 下注时间戳 |

索引：`(round_id, beast_index)` + `(sect_id, created_at DESC)`
