# 宗门参谋开发计划

页面右上角「同步」左边的「参谋」按钮：围绕**下一个目标**算清楚还差什么、要多久、怎么补最快。
纯前端（`apps/web/src/utils/advisor.ts` 纯函数 + `AdvisorDialog.vue` 渲染），只用 `state` 与装备视图；收益数字照抄服务端规则，只用于文案。

## 1. 晋升目标

- 目标 = `state.sectUpgrade`（下一级宗门）；为 null 时显示「宗门已满级」。
- 每种消耗资源一行：
  - 已够 →「已够」；
  - 还差 → `还差 D，每小时 +R，约 T`（T = 缺口 ÷ 当前 `ratePerHour`；不到 1 小时 / N 小时 / 48 小时起按天）；
  - 没有产出 →「目前没有产出」；仓库上限小于所需 →「存不下」。
- 耗时最长的资源标「瓶颈」；每个条件（建筑等级、弟子境界）一行，未达成的可跳转。
- 一句话总结：可晋升 / 「资源约 T 凑齐，瓶颈是 X」/「还有 N 个条件未达成」。

## 3. 战力提升

- 演武场未满级：「讨伐 / 镇妖塔 / 秘境战斗力 +10%」+ 花费。
- 主力：排除执事，按潜力分取前 5。潜力分 = 资质 × 0.45 + 战斗属性 × 0.35 + 境界分 × 0.2 + 战斗天赋 8；战斗属性含**手上未分配的悟道值**（`min(daoInsight, daoInsightRemaining)`，按攻击 → 防御 → 身法加到 100）。
- 理由标签：悟道值 ≥ 10 点未分配、资质 ≥ 75、单项战斗属性 ≥ 75、战斗天赋、境界前 2。
- 每人按战力公式（`realms.ts discipleCombatPower`）算增幅，取最高的 3 步：分配悟道值、突破（基数 +10）、换上背包里更好的装备（同一件只推荐一人）、空格 / 凡灵品按炼器坊能炼的最高品质估算、淬体丹。
- 重伤 / 受伤给说明。

## 4. 小红点

只在有明确高收益动作时亮：可晋升、演武场可升、坊市卖材料或神木兑换能补上缺口一半以上、灵石富余可直接买齐材料、主力可突破 / 有悟道值可分配 / 背包里有更好的装备。
日课、扫荡、拍卖待领等每日事项已在待办里，参谋不重复。
