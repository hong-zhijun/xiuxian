## 第 1 步：OpenRouter Decisions API 客户端

创建 `apps/server/src/infra/openrouter/decisions.ts`：

```ts
// 导出一个通用的 decide() 函数，解耦，不依赖游戏逻辑，方便其他系统复用。

const DECISIONS_URL = 'https://openrouter.ai/api/alpha/decisions';
const DEFAULT_MODEL = '~typesafe/jev-latest';

// 三种问题类型
interface NoulQuestion {
  type: 'noul';
  instructions: string;
  criteria: { true: string; false: string };
}
interface ChoiceQuestion {
  type: 'choice';
  instructions: string;
  criteria: Record<string, string>;
}
interface ScoreQuestion {
  type: 'score';
  instructions: string;
  criteria: string[];
}
type Question = NoulQuestion | ChoiceQuestion | ScoreQuestion;

// 三种回答类型
interface NoulAnswer { noul: number }
interface ChoiceAnswer { choice: string; probabilities: Record<string, number> }
interface ScoreAnswer { score: number }
type Answer = NoulAnswer | ChoiceAnswer | ScoreAnswer;

// 请求/响应
interface DecisionsRequest {
  model: string;
  state: string;
  questions: Record<string, Question>;
}
interface DecisionsResponse {
  answers: Record<string, Answer>;
}

/**
 * 调用 OpenRouter Decisions API。
 * @param apiKey  OPENROUTER_API_KEY
 * @param state   给模型的上下文文本
 * @param questions 结构化问题
 * @param model   默认 ~typesafe/jev-latest
 * @returns answers 对象
 * @throws Error  HTTP 失败时抛出
 */
export async function decide(
  apiKey: string,
  state: string,
  questions: Record<string, Question>,
  model: string = DEFAULT_MODEL,
): Promise<Record<string, Answer>> {
  const res = await fetch(DECISIONS_URL, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ model, state, questions } satisfies DecisionsRequest),
  });
  if (!res.ok) {
    const text = await res.text().catch(() => '');
    throw new Error(`Decisions API ${res.status}: ${text}`);
  }
  const data = (await res.json()) as DecisionsResponse;
  return data.answers;
}
```

同时导出所有 Question/Answer 类型，让游戏模块能引用。

### 7.2 `startRealmExplore(db, env, userId, realmId, discipleIds, now)`

逻辑（参考现有 `exploreSectRealm` 的校验流程）：
1. `draftFor(db, userId, now)` 获取 draft
2. 校验：秘境存在、等级足够、演武场存在、人数合法、去重、弟子存在+未伤+未外出、每日限次、无进行中探索
3. 扣入场费 `draft.requireResource(...)`
4. 算关卡数：`realm.requiredSectLevel <= 3 ? 3 : 5`
5. 用 `drawEncounters(realm.difficulty, 1, [])` 抽第一关遭遇
6. 创建 realm_explorations 记录（`insertRealmExplorationStatement`）
7. 写 explorations 表占坑（`insertExplorationStatement`，success=0）
8. `draft.commitDisciple(...)` 提交
9. 返回 `{ state, exploration: ActiveExplorationView }`

**注意：** `env` 参数从路由层传入 `c.env`，但这个函数不调 Decisions API，只是开始探索。

### 7.3 `chooseRealmExplore(db, env, userId, explorationId, choiceId, now)`

这是核心函数：
1. 查 realm_explorations 记录，校验 status='in_progress'
2. 解析 current_encounter JSON，校验 choiceId 有效
3. 解析秘境定义（realm_id → `findSecretRealm()`）
4. 构造 state 文本 + questions，调用 `decide(env.OPENROUTER_API_KEY, state, questions)`
5. **降级处理：** try/catch 包裹 decide()，失败时回退到本地随机判定（用 `explorationSuccessChanceBp` 算概率）
6. 根据 outcome 计算本关奖励：
   - 每关基础奖励 = `Math.floor(realmReward / (totalStages + 1))`（对每种资源）
   - great_success 奖励 ×1.5
   - failure 无本关奖励
7. 累加到 rewards_collected
8. 如果 failure：
   - status = 'failed'
   - injury.noul > 0.6 → 随机一名弟子受伤 10 分钟
   - 累计奖励入账（`resourceDeltaStatement`）
9. 如果 success/great_success 且 current_stage + 1 === total_stages：
   - status = 'completed'
   - 追加通关奖励（等于一关的基础奖励）
   - 全部奖励入账
   - 更新 explorations 表 success = 1
10. 否则 success/great_success：
    - 从剩余遭遇池抽下一关
    - current_stage + 1
    - 更新 current_encounter
11. `draft.commitDisciple(...)` 提交
12. 返回 `{ state, result: ExploreChoiceResultView }`

**Decisions API 调用方式：**
```ts
const answers = await decide(env.OPENROUTER_API_KEY,
  `秘境「${realm.name}」，难度${realm.difficulty}，队伍战力${power}。遭遇：${encounter.description} 玩家选择：${choice.label}`,
  {
    outcome: {
      type: 'choice',
      instructions: '根据队伍实力与选择的合理性判断结果',
      criteria: {
        great_success: '实力远超或选择巧妙，完美通过',
        success: '顺利通过',
        failure: '实力不足或选择失误，探索失败',
      },
    },
    injury: {
      type: 'noul',
      instructions: '弟子在本次遭遇中是否受伤',
      criteria: {
        true: '冒险行动或实力差距导致受伤',
        false: '安全通过',
      },
    },
  },
);
const outcome = (answers.outcome as ChoiceAnswer).choice;
const injuryProb = (answers.injury as NoulAnswer).noul;
```

```ts
async function onExploreChoose(explorationId: string, choiceId: string) {
  busy.value = true;
  try {
    const res = await chooseRealmExplore(explorationId, choiceId);
    state.value = res.state;
    exploreResult.value = res.result;
    if (res.result.nextEncounter) {
      activeExploration.value = {
        ...activeExploration.value!,
        currentStage: activeExploration.value!.currentStage + 1,
        encounter: res.result.nextEncounter,
      };
    } else {
      // 探索结束（通关或失败），显示最终结果后关闭
    }
  } catch (e) {
    // 错误提示
  } finally {
    busy.value = false;
  }
}
```
