# 灵股行情（股市）开发计划

> 给喜欢炒股的玩家一个「看消息、看 K 线、抓趋势」的玩法。人少，不做玩家之间撮合：**系统坐庄**，价格由服务端算法决定，玩家按当前价与系统买卖，用灵石结算。

## 1. 规则

| 项 | 规则 |
|---|---|
| 开放 | 宗门 3 级；入口在首页「市集」组「灵股」 |
| 标的 | 6 支股票 + 1 个综合指数（指数只看不交易） |
| 行情 | 每 1 分钟一跳（按 UTC 分钟取价） |
| 交易 | 只能买入 / 卖出，不做空、不加杠杆；按服务端此刻价格成交，不认客户端报价 |
| 手续费 | 买卖各 0.3%（向上取整），直接销毁 |
| 最短持仓 | 某支股票最近一次买入后 10 分钟内不能卖出这支 |
| 次数 | 每天 30 笔（买卖合计，UTC+8 自然日） |
| 持仓上限 | 每支股票的持仓成本不超过宗门灵石容量的 20% |
| 结算 | 卖出所得直接进灵石余额（不夹容量，与历练领取同一口径） |
| 排行 | 全服按「累计已实现收益」排名（前 10） |

**股票**（名字 / 板块 / 基准价 / 波动）：天工坊（炼器）、百草堂（药材）、灵矿商会（矿石）、镇妖司（战斗，波动最大）、云来商号（贸易，波动最小）、聚灵阁（灵气）。

## 2. 价格模型（不写库、可复算、不可预测）

- **种子**：首次使用时随机生成、存进数据库（`market_state`），**不在代码里**（开源仓库看不到，无法推算未来价格）。
- **对数价格** = ln(基准价) + 波动 × Σ 多尺度平滑噪声（周 / 日 / 4 小时 / 45 分钟 / 5 分钟五层）+ 全市场共同噪声 + 每分钟微小抖动 + 消息影响。
  平滑噪声有界，所以价格**均值回归**：长期围着基准价上下波动，不会涨上天或跌到零；长期持有的期望约为 0，系统靠手续费回收灵石。
- **消息**：时间按 3 小时一段，每段 70% 概率出一条「坊间传闻」（个股或全市场，利好 / 利空，强度 6%～18%）。
  消息公布后 5 分钟起，影响在 2～4 小时内逐步走出来，维持约 6 小时，再在 12 小时内回落。**75% 的消息属实**，其余是谣言（不应验或小幅反向）。
  所以看消息抓趋势有优势，但不是稳赚。
- 每分钟波动通常远小于来回 0.6% 的手续费 + 10 分钟最短持仓 + 每天 30 笔，**脚本高频刷差价无利可图**。
- 任意时刻价格都能直接算出来：K 线（1 小时 / 6 小时 / 1 天 / 7 天）按需现算 OHLC。

## 3. 实现

- 纯规则 `apps/server/src/modules/game/market.ts`：股票定义、噪声、消息生成与影响曲线、价格、K 线、手续费 / 持仓上限 / 锁定期。
- 迁移 `migrations/0043_stock_market.sql`：`market_state`（种子）、`stock_holdings`（每宗门每支：股数、持仓成本、最近买入时间、version）、`stock_trades`（成交流水：次数、收益榜、我的成交）。
- 服务：`getMarket`、`getMarketChart`、`tradeStock`（买 / 卖，一次受保护 batch，持仓 version 守卫）。
- 接口：`GET /game/market`、`GET /game/market/chart?stockId=&range=`、`POST /game/market/trade`。
- 前端 `MarketDialog.vue`：股票列表（现价、24 小时涨跌）、K 线（SVG 自绘，含均线）、买卖面板（股数、预估金额与手续费、持仓盈亏、可卖时间）、坊间消息、我的成交、收益榜；面板打开时每分钟自动刷新一次。
- 测试：`tests/game/market-rules.test.ts`（确定性、价格区间、消息、手续费、K 线）、`apps/server/test/market.test.ts`（买卖、锁定期、次数、持仓上限、收益）。
