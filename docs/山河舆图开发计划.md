# 山河舆图开发计划

> 多人玩法：全服 14 处灵地，宗门派弟子开辟 / 斗法夺地，坐镇期间每小时得到当地特产。
> 取代「灵脉争夺」（灵脉下线）。用「坐镇弟子完全锁定 + 镇守名额」让占地有真实的人力成本，限制强宗无成本扩张。

## 1. 规则（已确认）

### 1.1 地图与灵地

五个域，共 14 处灵地。每个域的灵地档位为 灵地（小）/ 福地（中）/ 洞天（大），中州两处为祖脉。

| 域 | 主产 | 灵地（小） | 福地（中） | 洞天（大） |
|---|---|---|---|---|
| 东 · 青木域 `east` | 药材 `herb` | 百草谷 | 万药林 | 青帝洞天 |
| 西 · 赤铜域 `west` | 矿石 `ore` | 赤砂岭 | 熔金峡 | 赤霄洞天 |
| 南 · 云泽域 `south` | 灵气 `spiritualEnergy` | 雾隐泉 | 云梦泽 | 碧落洞天 |
| 北 · 古墟域 `north` | 灵石 `spiritStone` | 残碑坡 | 旧市墟 | 藏金洞天 |
| 中州 `center` | 灵气 + 稀有 | 玄铁祖脉、神木祖脉（两处，档位「祖脉」） | | |

每小时产出（展示单位；代码里一律 ×1000 存最小单位）：

| 产出资源 | 灵地 | 福地 | 洞天 |
|---|---|---|---|
| 灵气 | 30 | 50 | 80 |
| 灵石 | 50 | 80 | 120 |
| 药材 / 矿石 | 75 | 120 | 180 |

- 祖脉：每小时灵气 80；另外每坐镇满 6 个整点小时得 1 个玄铁（玄铁祖脉）/ 神木（神木祖脉），即一天 4 个。
- 任何灵地不限宗门等级，谁都能打（只受镇守名额与等级差规则约束）。

### 1.2 开放与名额

- 宗门 3 级开放。
- 镇守名额：宗门 3～5 级 1 处，6～8 级 2 处，9 级及以上 3 处。名额满了不能再开辟 / 夺地（先撤回一处）。

### 1.3 坐镇弟子（核心）

- 每处灵地坐镇 3 人。**进攻的 3 人打赢后就地坐镇**（攻守绑定）；**不能换防**，想换人只能撤回山门后重新打。
- 坐镇期间弟子被强制改为「修炼」岗位（`cultivating`），照常修炼、可以破境、服药、祭炼装备。
- 坐镇期间**不能**：转岗 / 任执事 / 历练 / 秘境探索（两种入口）/ 讨伐 / 镇妖塔 / 比斗（切磋挑战）/ 进守擂阵容 / 论道 / 穿戴或卸下装备 / 被驱逐 / 再去打别的灵地。
- 已在守擂阵容里的弟子去坐镇：不用移出阵容，但被挑战时视为缺席（与在外历练同一处理），不会上场。
- 被打败的守军自动解锁回山门，不受伤；撤回山门时守军立刻解锁。

### 1.4 开辟与斗法

- 无主灵地有「盘踞妖兽」3 只：第 i 只的战力 = 进攻方第 i 人战力 × 0.9（不加守方加成）。打赢 = 开辟，灵地归你。
- 有主灵地：斗法夺地，3 对 3、三局两胜，沿用灵脉对决（每回合双方战力 ×0.85～1.15，守方 ×1.1；守军缺席的回合进攻方直接胜）。
- 进攻失败：进攻的每名弟子 30% 概率轻伤（疗伤 30 分钟）。妖兽战失败同样适用。
- 每天最多斗法 10 次（UTC+8 自然日），开辟妖兽也计入。
- 不能对「宗门等级比自己低 3 级及以上」的宗门斗法。
- 禁制护持：易主后 4 小时内不能被斗法（包括刚从妖兽手里开辟的）。撤回山门后灵地回到妖兽手里，没有禁制。
- 撤回冷却（迁移 0052）：撤回山门后 24 小时内，撤回的宗门不能再开辟 / 斗法这一处（易主也不清），堵「强队夺地 → 撤回 → 弱队再开辟」绕开攻守绑定。别的宗门不受影响。
- 出战校验与讨伐一致：不在外历练、不重伤、不是执事 / 交接期、不在疗伤、不在坐镇。

### 1.5 供奉（产出结算）

- **按整点小时结算**：只算完整持有的整点小时 [H:00, H+1:00)。占下时 `settled_at` = 下一个整点；每次结算推进到「当前时间向下取整到整点」。
- 易主 / 撤回时，先把原主已满的整点小时结算给原主，不满一小时的部分作废。
- 同一宗门的所有灵地在同一次结算里合并：一次结算写一条纪事「灵地供奉：药材 +180 · 灵气 +30」。
- 入账不超过该资源的仓库上限（溢出作废），用 `resourceCreditCappedStatement`。
- 定时任务（每 10 分钟）+ 打开面板 / 每个命令开头顺手结算。

### 1.6 纪事与通知

- 山河纪事（`world_site_logs`）：斗法（含开辟）、撤回、供奉三类。只保留 3 天（定时任务清理）。
- 面板筛选：「天下」= 全服斗法与撤回（不含别人的供奉）；「本宗」= 与本宗有关的全部（自己的供奉、自己打的、打自己的）。
- 天机录（事件日志）：灵地被夺写一条「灵地失陷」，守住写一条「击退来犯」（新系统事件 id `siteLost` / `siteHeld`）。
- 祖脉易主全服广播（`broadcastWorldBoss`，前缀 `【山河】`）。

### 1.7 灵脉下线

- 迁移把 `spirit_veins` 全部置为无主（表保留，不删数据）；定时任务停止结算灵脉。未结算的最多 10 分钟产出不补。
- 灵脉的接口、服务、纯规则文件、前端弹窗全部移除。
- 每日任务 `veinAttack`：**id 不改**（当天已抽到的任务存在库里），名字改为「山河斗法」，计数改为数今天在 `world_site_logs` 里本宗发起的斗法（含开辟）。
- 历史事件日志里的 `veinLost / veinHeld / veinExhausted` 名字保留在 `SYSTEM_EVENT_NAMES` 里（老记录还要显示）。

### 1.8 用语（界面文案统一）

山河舆图（玩法名）· 域 · 灵地 / 福地 / 洞天 / 祖脉 · 镇守名额（「镇守 2/3」）· 坐镇弟子 · 驱妖开辟 · 盘踞妖兽 · 斗法夺地（按钮「斗法」）· 今日斗法 3/10 · 击退来犯 · 失陷 · 禁制护持（「禁制护持 · 剩 2:13」）· 撤回山门 · 灵地供奉 · 山河纪事（天下 / 本宗）。时长一律显示小时 / 分钟，不换算时辰。

## 2. 实现

### 2.1 纯规则 `apps/server/src/modules/game/world.ts`（新）

不读库、不取时间、随机源参数注入（同 `veins.ts` / `tower.ts` 的写法）。

- 常量：`WORLD_UNLOCK_SECT_LEVEL = 3`、`WORLD_PARTY_SIZE = 3`、`WORLD_DAILY_BATTLES = 10`、`WORLD_PROTECT_MS = 4h`、`WORLD_LEVEL_GAP = 3`、`WORLD_DEFENDER_BONUS_BP = 1000`、`WORLD_BEAST_POWER_BP = 9000`、`WORLD_ATTACK_INJURY_CHANCE = 0.3`、`WORLD_ATTACK_INJURY_MS = 30min`、`WORLD_RARE_EVERY_HOURS = 6`、`WORLD_LOG_KEEP_MS = 3 天`、`WORLD_LOG_LIMIT = 60`（面板一次列出的条数）。
- `WORLD_REGIONS`：`{ id: 'east'|'west'|'south'|'north'|'center', name: '青木域'…'中州', resourceId: string | null }`（中州 null）。
- `WORLD_SITE_TIERS`：`lingdi` 灵地 / `fudi` 福地 / `dongtian` 洞天 / `zumai` 祖脉。
- `WORLD_SITES`：14 条 `{ id, name, regionId, tier, outputs: Record<resourceId, 每小时最小单位>, rare: { resourceId: 'xuantie'|'shenmu' } | null }`。
  site id 固定为 `east-lingdi`、`east-fudi`、`east-dongtian`、`west-…`、`south-…`、`north-…`、`center-xuantie`、`center-shenmu`（迁移按这 14 个 id 预置行）。
- `worldSiteCapOf(sectLevel)`：<3 → 0；3～5 → 1；6～8 → 2；≥9 → 3。
- `hourFloor(ms)` / `hourCeil(ms)`：向下 / 向上取整到整点（`HOUR_MS` 的整数倍；已经是整点时 ceil 返回自身）。
- `settleWorldSite({ outputs, rare, settledAt, rareHours, now })` → `{ hours, credits: Record<resourceId, number>, rareCount, nextSettledAt, nextRareHours }`：
  `boundary = hourFloor(now)`；`settledAt >= boundary` 时 hours = 0、什么都不给；否则 `hours = (boundary − settledAt) / HOUR`，credits = 每项 `rate × hours`；
  有 rare 时 `total = rareHours + hours`，`rareCount = floor(total / 6)`，`nextRareHours = total % 6`，credits 里加 `rare.resourceId: rareCount × 1000`（rareCount 为 0 时不加这一项）。
- `isWorldLevelGapBlocked(attackerLevel, defenderLevel)`：差 ≥ 3。
- `resolveWorldBattle({ attackers, defenders, random })`：与 `resolveVeinBattle` 完全相同的对决（直接把那段代码搬过来改名，`VeinRound` → `WorldBattleRound`）。
- `beastDefenders(attackers)`：返回 3 只妖兽 `{ name, power: floor(attacker.power × 0.9) }`，名字用 `盘踞妖兽 · 壹 / 贰 / 叁`。
  妖兽战不加守方 10%：给 `resolveWorldBattle` 加参数 `defenderBonus: boolean`（斗法 true，妖兽 false）。
- `parseGarrison(raw)`：同 `veins.ts`。

**结算**

- `processWorldSites(db, now, lazy = false)`：读全部有主灵地 → 按 holder 分组 → 每个宗门：对每处 `settleWorldSite`，hours = 0 的跳过；
  有产出时一个 `runGuardedBatch`：每处灵地的 guard + update（settled_at / rare_hours 推进）+ 资源入账（同一资源先在内存里合计，再按资源各一条 `resourceCreditCappedStatement`，容量 = 该资源配置容量 × 宗门等级倍率，仿 `energyCapacityOf` 写一个通用 `resourceCapacityOf(resourceId, sectLevel)`）+ 一条 `settle` 纪事（effects 为合计）。
  holder 宗门已不存在 → 该处置为无主。失败只跳过该宗门（`console.warn`）。最后（非 lazy 时）删 3 天前的纪事。
  lazy = true：距 settled_at 不满 1 小时的自然 hours = 0，不写库，无需额外判断。
- 「原主结算」：易主 / 撤回前，对那一处单独 `settleWorldSite`，把已满整点的产出记给原主（同样写一条 settle 纪事，只含这一处），再改 holder。

- `getWorld(db, userId, now)`：`processWorldSites(lazy)` → 面板。
- `attackWorldSite(db, userId, { siteId, discipleIds }, now)`：

  `requireWorldParty` → 对决 →
  胜：原主结算（有主时）、灵地写新主（`held_since = now`、`protected_until = now + 4h`、`settled_at = hourCeil(now)`、`rare_hours = 0`、garrison = 3 人 id）、3 人 `applyAssignment(draft, m, 'cultivating')`（已经是修炼的跳过）、守方天机录「灵地失陷」、纪事 battle（won=1）；祖脉广播。
